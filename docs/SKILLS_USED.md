## 2. Guiding Conflict Resolution Principles

1. **Flat vs Skew/Glass/3D**: Any skill recommending blur filters, heavy glow, stacked shadows, or 3D rotation is overridden by the brief's flat, clean, soft aesthetic.
2. **Typography Rules**: Self-hosted Instrument Serif (regular and italic) for display titles, Inter for body/UI. No font size below 13px anywhere.
3. **No Hard-Coded Colors**: All colors strictly driven by `--champion`, `--lavender`, `--violet`, etc., via Tailwind utilities.
4. **Vendor Component Code**: `src/vendor/ui/coral-dawn.jsx` cannot be recoloured cleanly via CSS variables without editing vendor code, so it is omitted from the landing page.
