# Component Research & Candidate Evaluation

This document details the browser and architectural research conducted across modern component ecosystems (**ui.shadcn.com**, **21st.dev**, **originui.com**, **magicui.design**, **shadcn.io blocks**, and open-source GitHub event platforms) to select the optimal primitives, carousels, and card layouts for EventMesh's "Champion & Lavender" design system.

## 2. Research Conclusions & Architectural Choices

1. **Primitive Layer**: Standardize on **Radix UI** primitives restyled with Tailwind CSS tokens and `cn()` utility functions. This ensures 100% WCAG AA accessibility, zero runtime CSS injection, and perfect keyboard navigation.
2. **Carousel Engine**: Standardize on **Embla Carousel** (`embla-carousel-react`). It is dependency-free, supports touch physics, auto-play with pause-on-hover/focus, and provides granular event hooks for dot indicators and slide counts.
3. **Icons**: Use **Lucide React** (`lucide-react`), already installed in the repository.
4. **Motion Engine**: Use **Framer Motion** (`framer-motion`), already installed in the repository, constrained strictly to subtle 2D fades, translates, and view-switching layout transitions.
5. **No Vendor Hacks**: Cleanly avoid modifying vendor files; use solid semantic tokens and pure CSS styling.
